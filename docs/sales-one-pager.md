# MesaLista — One-Pager

> Software de punto de venta para restaurantes. 100% local, sin mensualidades.

---

## ¿Qué es?

Un sistema completo para manejar tu restaurante:

- **Mesas** con estados visuales.
- **Punto de venta** táctil para tomar pedidos.
- **Cocina** con pantalla de órdenes en tiempo real.
- **Cobros** con efectivo, tarjeta o mixto.
- **Reportes** de ventas diarias, semanales y mensuales.
- **Usuarios** con roles (administrador, mesero, cocina).
- **Respaldos automáticos** para no perder información.
- **Impresión de recibos** en PDF.
